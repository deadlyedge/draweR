# winDrawer 产品需求与验收标准

## 1. 产品目标

winDrawer 是一个 Windows 桌面效率工具：用户可将一个轻量主窗口放在桌面上，为常用文件夹建立“抽屉”；选择抽屉后，在主窗口旁显示该文件夹内容，快速浏览并通过系统默认应用打开文件或子文件夹。

本文件定义目标产品行为，不绑定具体 Rust crate、UI 控件或 Windows API。MVP 应优先保留下列核心行为；“待决定”项在批准前不纳入必须交付范围。

## 2. 用户与核心场景

1. 用户启动应用后，从主窗口查看已配置的常用目录。
2. 用户添加一个目录作为抽屉，点击抽屉查看其一级内容。
3. 用户在抽屉中刷新目录、打开文件/子目录、调整窗口尺寸。
4. 用户从托盘隐藏/恢复应用或打开设置。
5. 用户调整颜色与透明度，即时预览效果，保存或取消。
6. 应用关闭并重新启动后，恢复设置、主窗口位置及各抽屉窗口尺寸。

## 3. 功能需求

### 3.1 主窗口

- **FR-MAIN-01**：显示已配置抽屉名称；目录不存在时应有明显的缺失状态，无抽屉时显示空状态并提供添加入口。
- **FR-MAIN-02**：通过文件夹选择器添加抽屉；显示名默认取路径最后一级目录名。
- **FR-MAIN-03**：拒绝添加空路径、无效目录或重复路径。Windows 路径重复判断不区分大小写，并应先展开环境变量；不得因路径大小写不同而重复添加同一目录。
- **FR-MAIN-04**：点击抽屉打开对应抽屉窗口；再次点击当前打开的抽屉可关闭它；同时最多显示一个抽屉窗口。
- **FR-MAIN-05**：抽屉窗口显示在主窗口右侧，并随主窗口移动保持相邻。
- **FR-MAIN-06**：主窗口可通过指定标题/Logo 区域拖动；锁定位置设置开启时不得拖动。拖动结束后保存位置。
- **FR-MAIN-07**：通过托盘可隐藏和恢复主窗口；恢复时使窗口可见且处于正常状态。
- **FR-MAIN-08**：主窗口应用主题 palette，支持无系统标题栏的桌面窗口形态。

### 3.2 抽屉窗口与文件浏览

- **FR-DRAWER-01**：枚举抽屉目录的一级子目录和一级文件，不递归；目录排在文件之前；两组各自按名称进行 Windows 用户预期的大小写不敏感排序。
- **FR-DRAWER-02**：每个条目显示名称与图标，长名称应截断或换行但仍可辨识；内容区可滚动，条目布局应随窗口大小自适应。
- **FR-DRAWER-03**：目录和普通文件尽量使用系统 Shell 图标。常见图片文件（bmp、gif、ico、jpeg、jpg、jfif、png、tif、tiff、webp）可显示按比例缩放的预览；预览失败时回退到 Shell 图标，最终回退到通用图标。
- **FR-DRAWER-04**：点击文件或目录时通过系统默认关联打开，不自行解释文件格式。错误应给出用户可理解的提示。
- **FR-DRAWER-05**：提供明确的刷新和关闭操作。刷新后正确反映新增、移除和改名条目。
- **FR-DRAWER-06**：显示当前目录路径。路径点击打开 Explorer 属于待决定功能，不应默认作为 MVP 验收条件。
- **FR-DRAWER-07**：抽屉窗口可拖动与调整尺寸；尺寸不得低于合理的最小可用尺寸，并按抽屉路径分别持久化。
- **FR-DRAWER-08**：对缺失目录、无权限目录、空目录和 Shell/图片处理失败提供稳定的空状态或错误反馈，不崩溃。
- **FR-DRAWER-09**：大量条目或慢速磁盘/网络目录不得导致 UI 长时间失去响应；刷新任务应能取消或使过期结果失效。

### 3.3 设置与主题

- **FR-SET-01**：设置窗口可修改位置锁定行为与 HSLA 主题参数。
- **FR-SET-02**：Hue 范围为 0–360；Saturation、Lightness、Alpha 范围为 0–100；超范围配置需夹取到有效范围。
- **FR-SET-03**：主题由一个集中计算过程生成，至少包含 accent、hover、pressed、border、window/content/card 背景、主/次文字色和窗体透明度；文字颜色根据背景亮度保证可读性。
- **FR-SET-04**：主题调整时即时更新设置预览、主窗口和当前抽屉窗口；不得由不同窗口各自计算并产生不一致主题。
- **FR-SET-05**：设置编辑采用临时工作副本。Save 提交并持久化；Cancel 或未保存关闭必须恢复原值和原主题。
- **FR-SET-06**：透明度参数范围是 0–100；为避免窗口完全不可见，应用窗体透明度最低值为 0.05（该限制如在 UI 框架下不适用，须通过技术决策确认替代行为）。
- **FR-SET-07**：图标大小配置默认值为 96，期望范围 32–512；每个图标的宽高保持一致，图片缩放时维持原始宽高比。
- **FR-SET-08**：所有设置变更应在正常退出前可靠保存；写入失败应保留可恢复的旧配置并提示/记录错误。

### 3.4 系统托盘与生命周期

- **FR-TRAY-01**：系统托盘提供 Show/Hide、Settings、Exit；双击托盘图标切换主窗口可见性。
- **FR-TRAY-02**：隐藏主窗口不退出应用；Exit 才触发正常关机。
- **FR-TRAY-03**：退出时停止后台任务、完成设置 flush、释放托盘和原生资源；退出后不得残留托盘图标或后台进程。
- **FR-TRAY-04**：启动、运行、退出以及可恢复错误应有结构化日志；日志不得包含不必要的隐私路径或敏感数据。

## 4. 配置与默认值要求

完整 TOML schema、读取规则和迁移约束见 [`CONFIGURATION_FORMAT.md`](CONFIGURATION_FORMAT.md)。MVP 至少保存：

- 是否随 Windows 启动（功能语义需按第 5 节决定）；
- 主窗口位置锁定状态；
- 图标大小；
- HSLA 主题值；
- 主窗口位置；
- 抽屉名称、路径及每个抽屉的窗口尺寸。

建议默认值：`start_with_windows=false`、`window_locked=false`、`icon_size=96`、主题 `[194, 100, 41, 60]`、主窗口初始坐标 `[100, 100]`。配置目录应在 [`TECHNICAL_DECISIONS.md`](TECHNICAL_DECISIONS.md) 中确定；不得因安装目录不可写而导致应用无法启动或丢失设置。

## 5. 待决定及后续功能

以下内容不是默认 MVP 验收项。用户明确批准并在本文更新后再实现：

1. **Windows 自启动**：设置界面/配置字段暗示此能力，但需确认 MVP 是否实现。若保留，开关必须真正注册/移除启动项，并在卸载/程序路径变化时正确处理；若不实现，应从用户界面移除或明确标示不可用。
2. **抽屉管理**：编辑名称、排序、移除已配置抽屉。
3. **打开 Explorer**：点击抽屉窗口底部路径打开该路径。
4. **缓存/预加载**：将图标或缩略图缓存到磁盘（例如 `.cachefiles`），并定义失效与清理策略。
5. **屏幕边缘吸附**：拖动主窗口靠近屏幕边缘时自动停靠。
6. **恢复默认值**：设置页按钮将值重置为默认；实现前需定义立即预览及 Save/Cancel 语义。
7. **窗口外点击关闭设置窗口**：属于交互增强；需与键盘焦点、辅助功能及多窗口体验一起验证。
8. **单实例、自动更新、国际化和其他窗口布局自定义**：均需独立产品决策。

## 6. 非功能需求

- **可靠性**：错误配置、目录移除、访问拒绝、图标查询失败、用户取消操作不应导致进程崩溃。
- **响应性**：耗时工作在后台运行；UI 更新回到 UI 线程；连续刷新不得由旧结果覆盖新结果。
- **数据安全**：配置写入具备原子性或等效保护；迁移/格式升级前保留备份；不得静默清空用户设置。
- **可维护性**：主题计算、配置访问和平台 Shell 操作集中实现，避免散布硬编码及平台调用。
- **DPI/多显示器**：窗口可见且尺寸可用；显示器配置变化后，屏幕外窗口应能恢复到有效工作区。坐标单位与转换规则见技术决策文档。
- **可测试性**：领域计算和配置处理可在不启动 UI 的情况下进行单元测试；Windows 专属行为另有 Windows 集成/手工验收。
- **可访问性**：控件具备可辨识名称、键盘焦点和合理的键盘操作；颜色不能是唯一状态指示。

## 7. 发布验收场景

- [ ] 首次运行创建有效默认设置；已存在配置可加载，保存后重启仍保留抽屉、主题、位置和尺寸。
- [ ] 可添加合法目录；拒绝空目录/重复目录；缺失目录可辨识。
- [ ] 同时只有一个抽屉；重复点击关闭；抽屉始终相对主窗口定位并随动。
- [ ] 文件列表非递归，目录在文件前，两组名称排序稳定；Refresh 正确更新内容。
- [ ] 文件、目录可由默认应用打开；图片预览失败不影响条目操作。
- [ ] 空目录、无权限、网络慢目录、超长名称和大量条目有可控反馈，UI 保持响应。
- [ ] 拖动/锁定、抽屉尺寸持久化、主窗口位置恢复正确；多显示器和 DPI 缩放验证通过。
- [ ] HSLA 范围、对比度、预览、Save/Cancel 和最低透明度符合本需求。
- [ ] 托盘显示/隐藏、双击、设置、退出可用；退出 flush 设置且没有残留资源。
- [ ] 自启动如果被批准保留，则启用/禁用均在 Windows 登录后实际生效。
